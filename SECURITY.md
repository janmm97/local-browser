# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report privately via GitHub: Security tab → "Report a vulnerability". Don't open a public issue.
We aim to reply within 7 days and to fix confirmed issues in the next release.

## Scope

local-browser lets an AI agent drive a real browser, so we especially want to hear about:

- ways a web page can bypass the policy file (blocked domains, approval prompts);
- ways a page or agent can approve its own risky action;
- anything that leaks data from the isolated profile or the action log.
